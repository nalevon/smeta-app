# Смета — автономное приложение (без входа, бесплатный ИИ Gemini)

Эта версия открывается как обычная ссылка, устанавливается на экран Android
как приложение, и голосовой разбор работает через бесплатный ИИ Google Gemini —
без входа в какой-либо аккаунт для того, кто пользуется страницей.

Файлы в этом комплекте:
- `index.html` — сама страница
- `manifest.json`, `icon.svg`, `sw.js` — чтобы Android предлагал «Установить как приложение»
- этот README

---

## Шаг 1. Получить бесплатный ключ Gemini

1. Откройте **aistudio.google.com**, войдите с любым Google-аккаунтом.
2. Найдите кнопку **Get API key** (обычно слева вверху) → **Create API key**.
3. Скопируйте ключ — строка вида `AIzaSy...`.

Бесплатный лимит — обычно несколько сотен-полторы тысячи запросов в день в зависимости от модели, этого с огромным запасом хватит на личное использование и на то, чтобы делиться с коллегами.

## Шаг 2. Ограничить ключ только своим сайтом (важно для безопасности)

Ключ будет виден внутри файла страницы — это неизбежно для варианта без сервера. Чтобы его нельзя было использовать с других сайтов:

1. Откройте **console.cloud.google.com** → раздел **APIs & Services → Credentials**.
2. Найдите свой ключ, откройте его настройки.
3. В разделе **Application restrictions** выберите **HTTP referrers (web sites)**.
4. Добавьте адрес вида `https://ваш-логин.github.io/*` (подставите свой адрес после шага 4 ниже — можно вернуться и дописать его позже).
5. Сохраните.

## Шаг 3. Вставить ключ в файл

1. Откройте `index.html` в любом текстовом редакторе (подойдёт даже «Блокнот» или редактор кода на телефоне).
2. Найдите строку:
   ```
   var GEMINI_API_KEY = 'ВАШ_КЛЮЧ_СЮДА';
   ```
3. Вставьте свой ключ между кавычками вместо `ВАШ_КЛЮЧ_СЮДА`, сохраните файл.

## Шаг 4. Выложить на GitHub Pages (бесплатный хостинг)

1. Зарегистрируйтесь на **github.com**, если ещё нет аккаунта.
2. Нажмите **New repository**, назовите, например, `smeta-app`, оставьте **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным — страница и так будет открыта всем по ссылке, так что это не проблема), нажмите **Create repository**.
3. На странице репозитория: **Add file → Upload files**, перетащите все файлы из этого комплекта (`index.html`, `manifest.json`, `icon.svg`, `sw.js`) — все в корень репозитория, не в подпапку. Нажмите **Commit changes**.
4. Зайдите в **Settings** репозитория → слева **Pages**.
5. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, ветка **main**, папка **/(root)**, нажмите **Save**.
6. Подождите 1-2 минуты, обновите страницу Pages — появится адрес вида `https://ваш-логин.github.io/smeta-app/`.

Теперь вернитесь к шагу 2 и впишите туда этот точный адрес (с `/*` на конце), если ещё не вписали.

## Шаг 5. Проверка

1. Откройте полученную ссылку в Chrome на телефоне.
2. Попробуйте надиктовать и нажать «Разобрать и посчитать» — должен прийти разбор.
3. В меню Chrome (⋮) должен появиться пункт «Установить приложение» или «Добавить на главный экран» — нажмите, иконка появится на рабочем столе и будет открываться без браузерной рамки.

## Как делиться с коллегами

Просто присылайте им ту же ссылку `https://ваш-логин.github.io/smeta-app/`. Им не нужно ничего вводить и никуда входить — откроют и сразу смогут пользоваться. У каждого свой прайс-лист (хранится в его телефоне), а все расчёты ИИ идут через ваш ключ Gemini — то есть технически считаются в ваш дневной бесплатный лимит на всех вместе. Для личной бригады это обычно некритично, но если ссылка разойдётся очень широко — лимит может закончиться раньше полуночи по тихоокеанскому времени (когда он сбрасывается).

## Если что-то не работает

- «В файле страницы не вставлен ключ Gemini» — вы не вставили ключ на шаге 3, либо сохранили файл с ошибкой.
- «Google заблокировал запрос с этого адреса» — ограничение по HTTP-referrer в шаге 2 указывает не тот адрес; впишите точный адрес своей страницы с GitHub Pages.
- «Исчерпан бесплатный дневной лимит» — подождите до завтра, либо подключите платный тариф в Google AI Studio (это уже не бесплатно).
- Если поменяли `index.html` после того как он уже был установлен как приложение на чьём-то телефоне — изменения подтянутся сами при следующем открытии с интернетом (service worker обновит кеш).
